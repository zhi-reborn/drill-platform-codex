# 阶段流程箭头视觉优化设计

## 目标

优化大屏 2 阶段卡片之间的连接箭头，使流程方向更清晰、状态更容易识别，并与现有应急指挥中心的青蓝科技风保持一致。

## 范围

- 仅修改 `ScreenView2.vue` 中阶段卡片连接器的标记与样式。
- 保持阶段卡片的尺寸、间距、点击行为和数据逻辑不变。
- 不调整下方环节流程、日志或概览区域。

## 视觉方案

连接器采用“信号接力器”造型：一条细轨道横向连接相邻卡片，轨道中央设置小型菱形方向节点，并以短促的尖角明确向右流向。连接器不再依赖多个彼此分散的箭头符号，从而减少拥挤和视觉噪声。

状态颜色沿用现有语义：

- 已完成：青绿色轨道与节点，表达信号已通过。
- 进行中：琥珀色高亮轨道与节点，配合低频流光和轻微脉冲。
- 待开始：低亮蓝灰色轨道与节点，保留方向但降低视觉权重。

光晕限制在连接器中央和轨道附近，避免遮挡阶段卡片边框。运行态动效使用 CSS 实现；系统启用减少动态效果时关闭动画。

## 实现约束

- 复用现有 `phase-sequence-arrow` 及状态类，不增加业务状态或 JavaScript 逻辑。
- 连接器维持当前 32px 布局宽度，避免改变四张阶段卡片的排布。
- 装饰元素继续设置 `aria-hidden="true"`，不增加无意义的读屏内容。
- 颜色、阴影和动画只作用于连接器相关选择器。

## 验收标准

1. 四张阶段卡片的布局与交互保持不变。
2. 三个连接器均呈现连续细轨道、中央菱形节点和明确向右的箭头尖角。
3. 已完成、进行中、待开始三种状态在颜色与亮度上可区分。
4. 进行中连接器具有克制的流光或脉冲，其他状态不持续抢眼。
5. `prefers-reduced-motion: reduce` 下连接器动画关闭。
6. 前端构建及大屏契约检查通过，并在浏览器中完成视觉核对。
