# 大屏4任务轨道视觉优化设计

## 目标

优化大屏4底部“当前环节待完成任务”区域，使当前任务与后续任务的层级更直观，并移除占据空间但不增加信息量的“候场矩阵”和“按执行顺序排列”文案。

## 范围

- 仅调整 `ScreenView4.vue` 中任务区域的模板、专属样式与对应结构测试。
- 保留现有任务筛选、排序、状态、执行人和实时更新逻辑。
- 不修改上方阶段卡片、流程跑道、后端接口或其他大屏。

## 视觉方向

采用“指挥任务轨道”布局，延续现有深海军蓝、青色信号线和琥珀色执行态的工业科幻语言。

### 信息层级

- 顶部仅保留当前环节名称和待完成任务总数。
- 左侧当前任务作为视觉锚点，保持更大的字号、琥珀色状态灯和底部能量扫描线。
- 右侧后续任务不再设置额外标题，任务卡直接与当前任务顶部对齐。
- 后续任务使用连续轨道线串联编号，依靠编号自然表达顺序，不再用解释性文案。

### 布局

- 当前任务约占内容区三成宽度，后续任务占其余空间。
- 后续任务卡在宽屏下按自适应列排列；当前目标视口中两张任务卡等宽铺满。
- 当前任务与后续任务之间使用带箭头的能量连接轨，强化“正在执行 → 即将执行”的方向感。
- 卡片内部统一状态、名称、负责人和序号的对齐规则，避免右侧卡片显得松散。
- 任务数量较多时仅后续任务区域滚动，不改变页面整体高度。

### 状态与动效

- `running` 使用琥珀色强调；`pending` 使用青蓝色弱强调。
- 仅执行中任务保留脉冲和扫描动效；连接轨使用低频流光，避免抢夺主流程图注意力。
- `prefers-reduced-motion` 下关闭循环动画。
- 语义标签继续包含任务状态与名称，不依赖颜色传达信息。

## 验收标准

- 页面不再显示“候场矩阵”和“按执行顺序排列”。
- `/director/screen4/90` 在 1159 × 863 视口下三张任务卡完整展示，无文字重叠或横向溢出。
- 当前任务仍明显高于后续任务的视觉权重，后续顺序可由编号和连接轨理解。
- 页面结构测试、类型检查和生产构建通过。
- 浏览器实页验证任务区域的布局、状态色、溢出和缩放表现。
