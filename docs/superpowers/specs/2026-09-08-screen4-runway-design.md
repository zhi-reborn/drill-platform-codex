# 大屏4独立跑道设计

## 目标

将大屏4所选阶段中的环节节点流程图替换为大屏1风格的蛇形能量跑道。跑道只展示环节名称和已完成/总任务数，保持大屏4现有阶段卡片、区域标题、演练概览与执行日志不变。

## 隔离边界

- 新建大屏4专属 `Screen4Runway.vue`，不导入大屏1的 `PhaseRing.vue`。
- 只修改 `ScreenView4.vue` 并新增大屏4专属文件与测试。
- 不修改大屏1、大屏2及其组件、样式或测试。
- 大屏4跑道独立拥有模板、布局算法和样式；后续修改大屏1、大屏2或大屏4不会互相影响。

## 组件与数据流

`ScreenView4.vue` 继续使用现有阶段选择和实时数据逻辑，将当前阶段的 `flowNodes` 映射为跑道节点：

- `name`：环节名称。
- `status`：`done`、`running`、`issue` 或 `pending`。
- `completed`：该环节已结束的叶子任务数。
- `total`：该环节叶子任务总数。

`Screen4Runway.vue` 只接收当前阶段名称、阶段状态和节点数组，不直接请求接口或连接 WebSocket。原页面数据更新后，跑道通过响应式 props 自动刷新。

## 跑道结构

- 使用 SVG 绘制深色蛇形跑道，环节过多时自动折返成多行。
- 已完成路径使用荧光绿，进行中路径和能量棒使用琥珀橙，待执行路径使用冷蓝，异常节点使用警示红。
- 普通节点显示环节名称和“已完成/总数”胶囊；不显示具体任务名称。
- 真实环节末尾追加不计入环节总数的“里程碑”靶心，全部完成后点亮。
- 进行中节点显示呼吸环和能量棒，能量棒位置随该环节任务完成比例推进。

## 页面集成与布局

- 保留 `flow-board` 外层网格背景、“当前环节/阶段预览”标题和实时连接状态。
- 用跑道替换原 `flow-viewport`、横向卡片、虚拟起止端帽及箭头。
- 跑道占用原流程图区域并在现有底部概览与日志上方自适应伸缩。
- 小视口降低字号、节点尺寸和轨道留白；遵循 `prefers-reduced-motion` 关闭非必要动画。
- 空阶段继续显示“该阶段暂无环节”。

## 测试与验证

- 先增加失败测试，断言大屏4使用独立跑道、节点只显示名称和完成数、不再渲染任务列表，且不导入大屏1组件。
- 为跑道几何函数测试单行、多行折返、状态路径及异常计数边界。
- 运行大屏1、大屏2既有测试，确认未发生回归。
- 运行全量前端测试、类型检查和生产构建。
- 在 `/director/screen4/90` 浏览器实测阶段切换、跑道状态、布局和控制台错误。

## 完成标准

1. 标记区域显示大屏1风格的蛇形能量跑道。
2. 每个环节只显示名称与已完成/总任务数。
3. 已完成、进行中、待执行、异常和里程碑状态清晰且美观。
4. 原顶部阶段选择、区域标题、底部概览和日志保持正常。
5. 大屏4跑道与大屏1、大屏2前端实现相互独立。
6. 测试、类型检查、构建与浏览器验证通过。
