# 进行中环节完整展示步骤设计

## 背景

数据大屏的流程节点默认只渲染前三条步骤，其余内容以“另有 N 个步骤…”代替。对于正在执行的环节，这会隐藏当前操作人员最需要关注的后续步骤。

## 目标

- 正在进行的环节展示全部叶子步骤。
- 已完成和待开始环节继续展示前三条步骤及剩余数量，保持流程轨道简洁。
- 保留现有步骤状态、颜色、图标、文字换行和节点聚焦效果。

## 方案

在 `ScreenView2.vue` 的节点步骤模板中，根据环节状态选择展示集合：

- `running`：使用完整的 `node.steps`。
- 其他状态：使用 `node.steps.slice(0, NODE_STEP_LIMIT)`。
- 仅非 `running` 节点在超过限制时渲染“另有 N 个步骤…”。

不修改接口、流程数据、环节状态计算或整体大屏布局。当前页面的进行中环节有四条步骤，因此第四条实际步骤会替换现有汇总行，节点高度基本不变。

## 验证

- 单元测试覆盖进行中节点返回全部步骤、非进行中节点仍受三条限制。
- 前端构建通过。
- 在 1159 × 863 的 Chrome 视口检查 `/admin/screen/90`：四条步骤均可见，没有“另有 1 个步骤…”；节点不被裁切，不遮挡下方概览和日志区域。
